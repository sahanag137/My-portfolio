# Sahana G | Personal Portfolio

A modern, minimal, and editorial-style personal portfolio built to showcase my skills, projects, technical journey, and development as a Computer Science (Data Science) student.

Designed with a warm paper-inspired aesthetic, subtle animations, and a clean layout to create a simple yet distinctive portfolio experience.



## ✨ Tech Stack

- **Frontend:** React, TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Typography:** Inter, Caveat
- **Version Control:** Git & GitHub

## 🎨 Design & UI

The portfolio follows a minimal editorial paper-inspired design.

- Warm beige / ivory background (`#EDE4D3`)
- Off-white paper surfaces (`#F8F5ED`)
- Dark charcoal typography (`#171512`)
- Subtle burgundy accents (`#6F2633`)
- Paper textures, thin borders, and soft shadows
- Handwritten annotations using Caveat font
- Clean typography using Inter
- Smooth transitions and subtle animations
- Responsive layout for different screen sizes

## 📌 Portfolio Sections

| Section | Description |

## 🛠️ Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/sahanag137/My-portfolio.git
```

**2. Navigate to the project directory**

```bash
cd My-portfolio
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the portfolio.

## 🖼️ Adding Your Photo

Place your profile photo inside:

```text
public/images/sahana.jpg
```

Recommended image specifications:
- Square or portrait orientation
- Minimum resolution: 600 × 700 px

## 📄 Adding Your Resume

Place your resume PDF inside:

```text
public/resume/Sahana-G-Resume.pdf
```

Update the resume component if your file name or path changes.

## 💻 Managing Projects

All project information is maintained in:

```text
src/data/projects.ts
```

The project data is organized into:

- `professionalProjects` – Projects focused on practical applications and professional development.
- `personalProjects` – Personal projects, experiments, and independent development work.

Projects can be added, updated, or removed by modifying the data file without changing the main UI components.

## 🏗️ Build for Production

To create an optimized production build:

```bash
npm run build
```

The production-ready files will be generated inside the `dist/` directory.

To preview the production build locally:

```bash
npm run preview
```
